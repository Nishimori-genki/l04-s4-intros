名前と年齢を入力し、自己紹介メッセージを表示するプログラムを作成してください。

1.	VS CodeをWSLに接続
2. 「<> Code」ボタン → HTTPS URL をコピー
3. VS Codeの左端のアクティビティバーのプライマリ サイド バーの「Clone Repository」
4. 2でコピーしたURLをペースト
5. クローン先フォルダを選択


```C
#include <stdio.h>

int main(void)
{
    // ここに処理を書いていく
    return 0;
}
```

### 変数の宣言とコメント
明確な名前付けとコメントで、コードの目的を明らかに
```C
char name[20];
int age; // ユーザーの年齢を格納
```

### 入力を受け取る
- %s → 文字列
- %d → 整数
```C
printf("名前と年齢を入力してください: ");
scanf("%s %d", name, &age);
```

### 出力を整えて表示
- %s → 文字列
- %d → 整数
```C
printf("%s さんは %d 歳です。\n", name, age);
```

### 実行

 VS Codeのターミナルを開いて、

 #### コンパイル
```Bash
$ gcc main.c -o main
```
または
```Bash
$ make
```

#### 実行
```bash
$ ./main 
名前と年齢を入力してください: taro 18
taro さんは 18 歳です。
```

### コーディングスタイルを意識して仕上げる
- 変数名に意味を持たせる
- コメントを適切に入れる
- 空白、改行、インデントを整える

VS Code の整形機能で確認（Shift + Alt + F）

```C
#include <stdio.h>
int main(void) {
    char name[20];
    int age;

    // 名前と年齢の入力 
    printf("名前と年齢を入力してください: ");
    scanf("%s %d", name, &age);
    // 結果を表示
    printf("%s さんは %d 歳です。\n", name, age);
    return 0;
}
```

### コミット
1. 左の「Source Control」アイコンをクリック
2. main.cの「＋」をクリックしてステージ
3. メッセージ(例: 「課題完成」)を入力して「✔ Commit」をクリック

### プッシュ
不要です。
プッシュした場合には、アクセス権が無いのでエラーになります。
なお、フォークした場合には、自分のリポジトリなので、プッシュできます。
